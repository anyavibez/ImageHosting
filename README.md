# ImageHosting

A free image hosting solution for **Discord** and **IMVU product preview banners**.

## Overview

This repository serves as a centralized image host for:
- **Discord image hosting** -- Store and share images via Discord CDN links
- **IMVU product preview banners** -- Showcase product categories with preview images

## Discord Images

Additional hosted images are available in the `DiscordImages/` folder.

## Usage

1. Upload your images to this repository
2. Use the **raw GitHub URL** or **GitHub Pages** to get a direct image link
3. Share the hosted image link on Discord, IMVU, or anywhere else

### Direct Raw URL Format

```
https://raw.githubusercontent.com/anyavibez/ImageHosting/main/<filename>.png
```
